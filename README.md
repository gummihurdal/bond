# Bond — A Daily Relationship Practice

A research-based daily practice for building a closer, more lasting relationship —
one conscious choice at a time.

Thirty small practices across ten areas drawn from relationship science
(Gottman, the Arons' self-expansion work, Johnson's EFT, perceived
responsiveness research, and the Harvard Study of Adult Development).

## Features
- Daily check-in with a three-state mark per practice (not yet / partly / done)
- "Why this works" insight behind every practice
- A private daily reflection note
- Insights: recent average per area + a personalised nudge toward the weakest area
- Journey: streak, 21-day chart, and a log of past days
- 100% static — no backend, no build step, no dependencies
- All data stays private in the browser (localStorage)

## Deploy
This is a single static file. Serve `index.html` from any host.

**GitHub Pages:** push to a repo, then Settings → Pages → Source: `main` / root.
